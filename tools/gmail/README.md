# Gmail MCP Integration

This directory contains configuration and setup for Gmail MCP server integration.

## Available Tools
- Send email
- Read emails
- Search emails
- Create draft
- List drafts
- Send draft
- Reply to email
- Add label
- Remove label
- Mark as read/unread

## Setup
Use a Gmail MCP server like `@gongrzhe/server-gmail-autoauth-mcp` or similar with OAuth2 authentication.
